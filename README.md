# Rock Paper Scissors

A simple and interactive **Rock Paper Scissors** game built using **Vanilla JavaScript**.

This project was created as a JavaScript team task for **Vortex**.

## Team

- **Youssef Waleed**
- **Youssef Maher**

We worked together on building the game, implementing the game logic, handling user interactions, and creating the interface.

## Game Features

- Choose **Rock**, **Paper**, or **Scissors**
- Computer makes a random choice
- Automatically determines:
  - Win
  - Lose
  - Draw
- Displays the player's choice
- Displays the computer's choice
- Keeps track of Player and Computer scores
- Restart the game and reset the score
- Simple and responsive user interface

## Game Logic

| Player | Computer | Result |
|---|---|---|
| Rock | Scissors | Win |
| Paper | Rock | Win |
| Scissors | Paper | Win |
| Same Choice | Same Choice | Draw |
| Otherwise | Otherwise | Lose |

The computer's choice is generated randomly using JavaScript's `Math.random()`.
